# Siam Network Map — Web Edition

Phone/desktop friendly website based on the original Siam Network Map v0.5 prototype.

## Run
Open `index.html` in a browser.

## GitHub Pages
1. Create/open a GitHub repository.
2. Upload `index.html`.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Open the generated HTTPS URL.

## Current features
- Admin/Staff demo login
- Dashboard
- SVG network map
- Node and fiber management
- Customer management
- Core usage
- Backup/restore
- Health check
- Mobile responsive UI

## Important
This web edition still uses browser localStorage for data and demo credentials. For real ISP production use, connect it to the PostgreSQL/Node backend and replace demo authentication with server-side authentication.
